MEGAPACK library for CH32V003A4M6 (SOP16)

• Adaptation of the MEGAPACK my library from CH32X033
• Uses only one timer, without interrupts
• Plays sound from protocol files, RAM buffers, and a "contiguous area"
• It's best to use the "contiguous area" for playing long sounds (over 10 seconds)

• Standard for software SPI (due to the lack of hardware SPI on the chip)
• All settings in <app_config.h>

Supported hardware:
• W25Q32,64,128 FLASH memory
• or TFT GRAPHIC display SPI ST7789
• or OLED TEXT display SPI SSD1306
• Sound

Library standard: 8000Hz samples, Headerless, Unsigned data.

Tested in hardware, works as expected.
